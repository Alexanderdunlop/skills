# Skills For Good Vibes

My skills that I use to build real products (good vibes).

This is super opinionated to my style, take only what you want/need.

IMO, skills should be small and easy to understand.

If you want to keep up with my opinions you can join others:

[My Content](https://alexdevdunlop.substack.com/)

## Skills

- **[test-interrogate](skills/development/test-interrogate/SKILL.md)** — Interrogate you on what unit tests to write after a PR, then implement and triage them.
- **[claude-md](skills/development/claude-md/SKILL.md)** — Generate, update, or audit a project's CLAUDE.md using codebase interrogation and Apple's leaked patterns.
- **[explore-options](skills/development/explore-options/SKILL.md)** — Force Claude to trace existing code, lay out 2-3 real approaches with tradeoffs, and wait for a pick before writing any code on work with a design choice in it.
- **[create-skill](skills/meta/create-skill/SKILL.md)** — Create new skills that actually trigger and actually change Claude's behaviour, using two named tests to catch the common failure modes.
- **[audit-skill](skills/meta/audit-skill/SKILL.md)** — Score an existing SKILL.md line-by-line with the would-have-anyway and trigger tests, and report the kill count.
